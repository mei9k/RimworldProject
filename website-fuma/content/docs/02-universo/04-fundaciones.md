# Fundaciones

Las Fundaciones son enclaves clave para educación, defensa, investigación, seguridad y exploración a escala solar.

## Lista base

- F-01 Akapusu: astilleros.
- F-02 Stellvia: academia.
- F-03 Seluva: academia.
- F-04 Odyssey: militar.
- F-05 Vision: seguridad y datos.
- F-06 El Santo: investigación y desarrollo.
- F-07 Ultima: exploración espacial.

## Uso narrativo

Las Fundaciones actúan como nodos de poder, comercio, conocimiento y presión política entre facciones.
